# ADR-0001: Record architecture decisions

Status: accepted

## Context
The project is public and long-lived; methodology choices (BSI TR-03183-1) must be traceable.

## Decision
Every architecture decision is recorded as a numbered ADR in `docs/adr/` (Context, Options, Decision, Consequences). Deviations from the product brief require an ADR before code.

## Consequences
ADRs are part of review. Superseded ADRs stay in place with status `superseded by ADR-XXXX`.
